# E-Commerce Sales & Customer Analytics

## About the Project

This project is an interactive Power BI dashboard developed to analyze e-commerce sales, customer behavior, product performance, profitability, marketing performance, delivery, returns, and cancellations.

The project uses multiple related datasets to build a structured data model and provides interactive dashboards for exploring business performance across different dimensions.

## Tech Stack Used

- Power BI
- Power Query
- DAX
- Data Modeling
- CSV

## Project Analysis

- Analyzed approximately 138K e-commerce orders from 2021 to 2025.
- Analyzed total revenue, profit, orders, customers, average order value, profit margin, return rate, and cancellation rate.
- Analyzed sales performance across different product categories and regions.
- Analyzed customer segments and purchasing behavior.
- Analyzed marketing performance and its relationship with sales.
- Analyzed delivery performance and order status.
- Analyzed product and category-level performance.
- Analyzed returns and cancellations to understand their impact on business performance.

## Work Done

- Imported and cleaned multiple datasets using Power Query.
- Created relationships between customer, sales, order item, product, and date tables.
- Created a dedicated Date table for time-based analysis.
- Created DAX measures for business KPIs.
- Designed interactive KPI cards, charts, and slicers.
- Created multiple dashboard pages for sales, customers, products, marketing, delivery, and returns analysis.

## Dashboard

The Power BI report contains multiple interactive pages with KPI cards, charts, filters, and visualizations for exploring e-commerce business performance.
